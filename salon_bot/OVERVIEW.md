## 📊 Сравнение До/После

### Ввод телефона

**До:**
```python
if not phone.startswith('+996') or len(phone) != 13:
    error()
```
Принимает: `+996555123456`

**После:**
```python
if not phone.startswith('+'):
    digits = ''.join(filter(str.isdigit, phone))
    if len(digits) == 9:
        phone = f"+996{digits}"
```
Принимает:
- ✅ `555123456`
- ✅ `996555123456`
- ✅ `+996555123456`
- ✅ `555 123 456`
- ✅ `555-123-456`
