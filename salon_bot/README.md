Телеграм-бот для салонов красоты с улучшенным интерфейсом и быстрой записью.

## ✨ Ключевые улучшения

### 1. 📱 Упрощенный ввод телефона
- ❌ Было: Только строгий формат +996XXXXXXXXX
- ✅ Стало:

- Улучшенная типографика

### 3. ⚡ Быстрая запись (~1 минута)
- Убрана лишняя информация

- Быстрая навигация назад

- Услуги: `Стрижка • 600с • 60м`

## 🚀 Установка

### 1. Скопируйте файлы
Скопируйте все файлы из `salon_bot/` в ваш проект.

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте .env
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
```

### 4. Запустите бота
```bash
python -m bot.main
```

## 🎯 Процесс записи

1. **Салон** → Быстрый выбор из списка
2. **Услуга** → Компактный формат цена/время
3. **Мастер** → Имя и специализация
4. **Дата** → 7 дней вперед
5. **Время** → Сетка 4x4 для быстрого выбора
6. **Телефон** → Гибкий формат ввода
7. **✅ Готово!** → Информация о мастере

**Время:** ~45-60 секунд

## 🔧 Технические детали

### Упрощенная валидация телефона
```python
if not phone.startswith('+'):
    digits = ''.join(filter(str.isdigit, phone))
    if len(digits) == 9:
        phone = f"+996{digits}"
```

### Компактная сетка времени
