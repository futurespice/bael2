### 2. 📱 Ввод телефона

#### До:
```python
# Строгая валидация
if not phone.startswith('+996') or len(phone) != 13:
    return error
```

**Принимается только:** `+996555123456`

#### После:
```python
# Гибкая валидация с автоформатированием
if not phone.startswith('+'):
    digits = ''.join(filter(str.isdigit, phone))
    if len(digits) == 9:
        phone = f"+996{digits}"
```

**Принимается:**
- ✅ `555123456` → `+996555123456`
- ✅ `996555123456` → `+996555123456`
- ✅ `+996555123456` → `+996555123456`
- ✅ `555 123 456` → `+996555123456`
- ✅ `555-123-456` → `+996555123456`
