## 1. Дополнительные цены товаров

Партнёры доставляют товары в регионы, где базовая цена невыгодна. Админ задаёт доп цены при создании/редактировании товара. Партнёр выбирает нужную доп цену при оформлении ручного заказа.

### Правила

- Доступна **только для ручных заказов** (manual orders)
- Товар с доп ценой **не может быть бонусным** в этой позиции
- Товар с доп ценой **не может быть бракованным**
- У одного товара может быть **несколько** доп цен
- Доп цены устанавливает **только админ**

### Объект AdditionalPrice

```json
{
  "id": 1,
  "name": "Цена для Ош",
  "price": "150.00",
  "is_active": true,
  "created_at": "2026-04-03T10:00:00Z",
  "updated_at": "2026-04-03T10:00:00Z"
}
```

| Поле         | Тип      | Описание                                  |
|--------------|----------|-------------------------------------------|
| `id`         | integer  | ID доп цены (read-only)                   |
| `name`       | string   | Название, max 200 символов. Пример: "Цена для Ош" |
| `price`      | decimal  | Цена, min 0.01                            |
| `is_active`  | boolean  | Активна ли (default: true)                |
| `created_at` | datetime | Дата создания (read-only)                 |
| `updated_at` | datetime | Дата обновления (read-only)               |

### Где видны доп цены

Доп цены отдаются в массиве `additional_prices` в следующих эндпоинтах:

- `GET /api/products/products/` — список товаров
- `GET /api/products/products/{id}/` — детали товара
- `GET /api/stores/partner-inventory/` — инвентарь партнёра (внутри объекта `product`)

### Создание товара с доп ценами (только админ)

**POST** `/api/products/products/`

```json
{
  "name": "Мороженое",
  "unit": "piece",
  "is_weight_based": false,
  "is_bonus": false,
  "manual_price": "100.00",
  "additional_prices": [
    {"name": "Цена для Ош", "price": "120.00"},
    {"name": "Цена для Нарын", "price": "140.00"}
  ]
}
```

Ответ содержит `additional_prices` с полными объектами (включая `id`, `created_at`).

### Редактирование доп цен (только админ)

**PATCH** `/api/products/products/{id}/`

```json
{
  "additional_prices": [
    {"id": 1, "name": "Обновлённая цена Ош", "price": "125.00"},
    {"name": "Новая цена Жалал-Абад", "price": "135.00"}
  ]
}
```

Логика SMART UPSERT:
- С `id` — обновляет существующую доп цену
- Без `id` — создаёт новую
- Доп цены, **не пришедшие** в запросе — **удаляются**

Чтобы удалить все доп цены: `"additional_prices": []`

### Использование доп цены в ручном заказе

**POST** `/api/orders/partners/manual-orders/`

```json
{
  "store": 1,
  "items": [
    {
      "product": 42,
      "quantity": 10,
      "additional_price_id": 1
    },
    {
      "product": 43,
      "quantity": 5
    }
  ],
  "prepayment": 0
}
```

| Поле                 | Тип     | Обязательное | Описание                                     |
|----------------------|---------|-------------|----------------------------------------------|
| `additional_price_id`| integer | Нет         | ID доп цены из списка `additional_prices` товара |

**Приоритет цены**: `additional_price_id` > `price` (ручная) > `final_price` (базовая)

**Валидация**:
- Доп цена должна принадлежать указанному товару
- Доп цена должна быть активной (`is_active: true`)
- `is_bonus: true` + `additional_price_id` — **ошибка 400**

**Ошибки**:
```json
{"error": "Доп цена с ID 99 не найдена или не активна"}
{"error": "Доп цена \"Цена для Ош\" не принадлежит товару \"Кефир\""}
{"error": "Товар с доп ценой не может быть бонусным (Мороженое)"}
```

## 2. Долги партнёра

Новый эндпоинт для просмотра долгов магазинов перед конкретным партнёром.

### 2.1 Список магазинов-должников

**GET** `/api/stores/partner-debts/`

**Доступ**: партнёр (видит только свои), админ (видит все)

**Query-параметры**:

| Параметр     | Тип     | Описание                                  |
|--------------|---------|-------------------------------------------|
| `partner_id` | integer | Фильтр по партнёру (только для админа)     |
| `show_all`   | string  | `"true"` — показать и магазины с нулевым долгом. По умолчанию скрыты |

**Пример запроса** (партнёр):
```
GET /api/stores/partner-debts/
```

**Пример запроса** (админ, конкретный партнёр):
```
GET /api/stores/partner-debts/?partner_id=5
```

**Ответ** `200 OK`:
```json
[
  {
    "store_id": 1,
    "store_name": "Магазин Алия",
    "store_address": "ул. Манаса 42",
    "store_phone": "+996555123456",
    "total_orders_amount": 50000.0,
    "total_prepayment": 10000.0,
    "total_paid_debt": 25000.0,
    "outstanding_debt": 15000.0
  }
]
```

| Поле                  | Тип   | Описание                                      |
|-----------------------|-------|-----------------------------------------------|
| `store_id`            | int   | ID магазина                                   |
| `store_name`          | string| Название магазина                             |
| `store_address`       | string| Адрес                                         |
| `store_phone`         | string| Телефон                                       |
| `total_orders_amount` | float | Сумма всех принятых заказов                   |
| `total_prepayment`    | float | Сумма всех предоплат                          |
| `total_paid_debt`     | float | Сумма всех погашений долга                    |
| `outstanding_debt`    | float | Остаток долга (не может быть < 0)             |

Формула: `outstanding_debt = total_orders_amount - total_prepayment - total_paid_debt`

### 2.2 Детали долга магазина

**GET** `/api/stores/partner-debts/{store_id}/`

**Доступ**: партнёр (свои), админ (все, с опциональным `?partner_id=`)

**Ответ** `200 OK`:
```json
{
  "store": {
    "id": 1,
    "name": "Магазин Алия",
    "address": "ул. Манаса 42",
    "phone": "+996555123456"
  },
  "total_orders_amount": 50000.0,
  "total_prepayment": 10000.0,
  "total_paid_debt": 25000.0,
  "outstanding_debt": 15000.0,
  "recent_payments": [
    {
      "id": 101,
      "order": null,
      "store": 1,
      "amount": "5000.00",
      "paid_by": 5,
      "paid_by_name": "Партнёр Иванов",
      "received_by": 5,
      "received_by_name": "Партнёр Иванов",
      "comment": "Частичная оплата",
      "created_at": "2026-04-01T10:30:00Z"
    }
  ],
  "orders": [
    {
      "id": 1001,
      "order_type": "manual",
      "total_amount": 50000.0,
      "prepayment_amount": 10000.0,
      "debt_amount": 40000.0,
      "paid_amount": 25000.0,
      "outstanding_debt": 15000.0,
      "confirmed_at": "2026-04-01T10:00:00Z",
      "created_at": "2026-04-01T09:00:00Z"
    }
  ]
}
```

| Поле               | Тип    | Описание                                |
|--------------------|--------|-----------------------------------------|
| `store`            | object | Информация о магазине                   |
| `recent_payments`  | array  | Последние 20 погашений (DebtPayment)    |
| `orders`           | array  | Последние 50 принятых заказов           |

**Ошибки**:
```json
// 404
{"error": "Магазин с ID 99 не найден"}
// 403
{"error": "Доступно только для партнёров и админов"}
```

## 3. Оплата долга — изменения

**POST** `/api/stores/stores/{store_id}/pay-debt/`

### Что изменилось

1. **Платёж привязывается к магазину напрямую** (`store`), а не к заказу
2. **Админ может указать `partner_id`** — кому атрибутировать платёж
3. **Не нужен последний заказ** — можно погашать долг даже если у магазина нет заказов

### Тело запроса

```json
{
  "amount": 5000,
  "comment": "Частичное погашение долга",
  "partner_id": 5
}
```

| Поле         | Тип     | Обязательное | Описание                                          |
|--------------|---------|-------------|---------------------------------------------------|
| `amount`     | decimal | Да          | Сумма погашения, min 0.01, не больше долга магазина |
| `comment`    | string  | Нет         | Комментарий                                        |
| `partner_id` | integer | Нет         | ID партнёра-получателя (только для админа)         |

### Кто может платить и что происходит

| Роль     | `received_by`                                    | Сценарий                            |
|----------|--------------------------------------------------|-------------------------------------|
| Партнёр  | Сам партнёр (автоматически)                       | Партнёр получает деньги от магазина  |
| Админ    | Указанный `partner_id` или `null`                 | Админ корректирует долг             |
| Магазин  | `null`                                            | Магазин платит общий долг           |

### Ответ `201 Created`

```json
{
  "success": true,
  "message": "Долг успешно погашен",
  "payment": {
    "id": 101,
    "order": null,
    "store": 1,
    "amount": "5000.00",
    "paid_by": 3,
    "paid_by_name": "Админ",
    "received_by": 5,
    "received_by_name": "Партнёр Иванов",
    "comment": "Частичное погашение долга",
    "created_at": "2026-04-03T12:45:00Z"
  },
  "store_debt_before": 20000.0,
  "payment_amount": 5000.0,
  "store_debt_after": 15000.0,
  "store_total_paid": 35000.0
}
```

### Ошибки

```json
// amount не указан
{"error": "Укажите amount"}

// amount <= 0
{"error": "Сумма должна быть больше 0"}

// amount > store.debt
{"error": "Сумма погашения (60000.00 сом) превышает долг магазина (50000.00 сом)"}

// Неверный partner_id (только админ)
{"error": "Партнёр с ID 99 не найден"}
```

## 4. Изменения в существующих эндпоинтах

### GET /api/products/products/ — добавлено поле `additional_prices`

Каждый товар в списке теперь содержит массив доп цен:

```json
{
  "id": 42,
  "name": "Мороженое",
  "final_price": "100.00",
  "additional_prices": [
    {"id": 1, "name": "Цена для Ош", "price": "120.00", "is_active": true, ...},
    {"id": 2, "name": "Цена для Нарын", "price": "140.00", "is_active": true, ...}
  ]
}
```

### GET /api/stores/partner-inventory/ — доп цены внутри товара

Товар в инвентаре партнёра содержит `additional_prices`:

```json
{
  "items": [
    {
      "product": {
        "id": 42,
        "name": "Мороженое",
        "final_price": "100.00",
        "additional_prices": [
          {"id": 1, "name": "Цена для Ош", "price": "120.00", "is_active": true, ...}
        ]
      },
      "quantity": 100,
      "available_quantity": 80
    }
  ]
}
```

### DebtPayment — новые поля

Объект `DebtPayment` теперь содержит:

| Поле    | Тип          | Описание                                       |
|---------|--------------|-------------------------------------------------|
| `order` | integer/null | ID заказа (null для прямых платежей)             |
| `store` | integer      | ID магазина (всегда заполнено, обязательное поле)|
